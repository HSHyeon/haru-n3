# OTOBA (音葉)

좋아하는 J-POP으로 배우는 나만의 일본어

React + TypeScript + Vite로 만든 개인용 일본어 학습 초안입니다.

## 실행

```sh
npm install
npm run dev
```

`npm run build`로 타입 검사 및 배포 빌드를 실행합니다. 권장 Node 버전은 22 LTS입니다.

N3 일상 단어 6개, 음악 주제 기초 단어 6개, 문법 3개의 샘플을 포함합니다. 음악 공부방에서 발음 힌트, 브라우저 음성 듣기, 음악 단어 퀴즈, 감상 노트를 사용할 수 있습니다. 예문은 학습용 창작 문장이며 아티스트 가사나 음원은 포함하지 않습니다. 공식 기출문제나 N3 전체 범위를 제공하지 않습니다. 퀴즈 결과와 오답은 현재 브라우저의 localStorage에 저장되며 기기 간 동기화되지 않습니다. 발음은 브라우저의 일본어 음성 지원에 따라 달라집니다.

## 개인정보와 인증 정보

`.env` 파일, 키 파일, 개인 학습 참고 문서, 로컬 설정은 Git 추적에서 제외합니다. 환경 변수 안내가 필요하면 `.env.example`에 이름과 가짜 값만 기록하세요. `VITE_*` 값은 브라우저에 노출되므로 비밀 키를 넣으면 안 됩니다. 브라우저에 저장되는 퀴즈 기록과 감상 노트는 저장소에 포함되지 않습니다.

## PWA 설치와 오프라인

배포 주소를 휴대폰 Safari 또는 Chrome에서 열고 로그인한 뒤, 하단에서 **오프라인 준비 완료**를 확인하세요. iPhone은 공유 메뉴 → 홈 화면에 추가, Android Chrome은 메뉴 → 앱 설치/홈 화면에 추가로 설치합니다. 지원되는 브라우저에는 앱 내 설치 버튼도 표시됩니다.

- 서비스 워커는 배포 빌드에서만 등록됩니다. 로컬 검증: `npm run build` → `npm run preview`.
- 단어·문법·퀴즈 화면과 앱 아이콘을 기기에 저장합니다. 최초 방문과 로그인은 온라인 연결이 필요합니다. 외부 웹폰트와 일본어 음성의 오프라인 사용 여부는 기기 지원에 따라 달라집니다.
- 로그인 페이지, 인증 콜백, API 요청, 외부 리소스는 캐시하지 않습니다. 온라인 접근 거부/로그인은 캐시된 앱으로 대체하지 않습니다. 오프라인 저장을 마친 기기에서는 로그인 서버에 연결하지 않고 학습 화면을 열 수 있으므로 개인 기기에서 사용하세요.
- 새 버전은 사용자에게 업데이트를 안내한 뒤 활성화합니다. 앱 데이터는 브라우저에 저장되고 기기 간 동기화되지 않습니다. 브라우저의 사이트 데이터 삭제 시 학습 기록과 오프라인 파일도 사라질 수 있습니다.
- `node --test tests/pwa.test.mjs`는 빌드 후 실행하며 설치 자산, 오프라인 응답, 로그인 페이지 캐시 차단을 검사합니다.
- 아이콘 원본은 `public/favicon.svg` 하나입니다. `npm run icons:generate`로 모든 PNG·ICO를 재생성하며, 빌드 전에도 자동 실행됩니다.

## 곡별 N3 학습 컬렉션

음악 공부방에서 요루시카 3곡(ただ君に晴れ, 花に亡霊, 春泥棒)을 선택할 수 있습니다. 곡마다 공식 영상 연결, 주제에 연결한 단어 4개·문법 2개, 단어 퀴즈·문법 확인 문제, 곡별 감상 노트를 제공합니다.

예문과 문제는 학습용 창작 자료이며, 실제 가사에서 추출한 표현이나 가사 해설이 아닙니다. 기초 복습을 포함한 N3 대비 학습 코스이며 공식 JLPT 어휘 등급표를 의미하지 않습니다. AI API와 가사 수집 기능은 연결하지 않았습니다.

새 단어는 기존 12개 뒤에 추가하여 기존 학습 기록을 유지합니다. 단어 오답은 공통 오답장에, 문법 오답은 음악 공부방의 곡별 문법 오답에 표시합니다. 학습 진도·문법 답안·곡별 메모는 현재 브라우저에만 저장됩니다. 공식 영상은 사용자가 누르면 YouTube에서 불러오며 네트워크 연결이 필요합니다. 앱 내 재생 제한 시 공식 영상 링크를 이용하세요.

## 코드 정리

Prettier로 TypeScript·React·CSS·JSON·Markdown 형식을 통일합니다.

```sh
npm run format        # 자동 정리
npm run format:check  # 정리가 필요한 파일 확인
```

VS Code에서 저장할 때 자동 정리하려면 Prettier 확장을 설치하고 기본 포맷터를 Prettier로 지정한 뒤 `Format On Save`를 켜세요. 저장소에는 개인 편집기 설정을 포함하지 않습니다. 설정은 `.prettierrc.json`, 제외 대상은 `.prettierignore`에 있습니다. 빌드 결과와 인증 파일, 개인 학습 메모는 포맷 대상에서도 제외합니다.

## 다크 테마와 모션

Tailwind CSS의 Vite 플러그인을 사용합니다. 공통 색상과 모션 토큰은 `src/style.css`의 `@theme`에 있으며, 레이아웃과 다크 컴포넌트 스타일은 같은 파일의 components 레이어에 모았습니다. 중복 테마 선언과 사용하지 않는 예전 장식 스타일은 제거했습니다. 기존 레이아웃은 components 레이어에 유지하고 유틸리티가 필요한 부분을 덮어쓸 수 있게 구성했습니다. Tailwind Preflight는 적용하지 않습니다.

기본 배경은 짙은 남색이고, 본문·보조 글자·버튼·정답·오답 상태를 구분했습니다. 페이지 진입과 학습 단계 전환, 모달·해설에는 짧은 모션을 적용합니다. `prefers-reduced-motion`에서는 애니메이션·전환을 끕니다.

## 브랜드와 기존 기록

표시 이름은 OTOBA (音葉)입니다. 기존 설치 앱의 동일성을 유지하기 위해 manifest의 id·scope·start_url은 그대로 두었습니다. 학습 기록을 유지하도록 기존 localStorage 키와 오프라인 캐시 접두어, 앱 식별 메타 태그도 유지합니다. GitHub 저장소명과 배포 주소는 변경하지 않았습니다.

## 아이콘 수정

로고 도형과 색은 `public/favicon.svg`만 수정하세요. `scripts/generate-icons.mjs`가 이 SVG를 렌더링하여 브라우저 탭·설치 앱·iPhone용 PNG 6개와 ICO 1개를 만듭니다. Android maskable 아이콘은 같은 도형에 잘림 방지 여백과 SVG에서 읽은 배경색을 적용합니다. 생성된 파일은 직접 편집하지 않습니다. 렌더러는 개발 의존성이며 브라우저 번들에는 포함되지 않습니다.

```sh
npm run icons:generate # 아이콘만 재생성
npm run build          # 아이콘 재생성 → 타입 검사 → 앱 빌드
```
