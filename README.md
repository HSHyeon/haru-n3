# 하루 · N3 공부
React + TypeScript + Vite로 만든 개인용 일본어 학습 초안입니다.

## 실행

```sh
npm install
npm run dev
```

`npm run build`로 타입 검사 및 배포 빌드를 실행합니다. 권장 Node 버전은 22 LTS입니다.

N3 일상 단어 6개, 음악 주제 기초 단어 6개, 문법 3개의 샘플을 포함합니다. 음악 공부방에서 발음 힌트, 브라우저 음성 듣기, 음악 단어 퀴즈, 감상 노트를 사용할 수 있습니다. 예문은 학습용 창작 문장이며 아티스트 가사나 음원은 포함하지 않습니다. 공식 기출문제나 N3 전체 범위를 제공하지 않습니다. 퀴즈 결과와 오답은 현재 브라우저의 localStorage에 저장되며 기기 간 동기화되지 않습니다. 발음은 브라우저의 일본어 음성 지원에 따라 달라집니다.

## 개인정보와 인증 정보

`.env` 파일, 키 파일, 개인 학습 참고 문서, 로컬 설정은 Git 추적에서 제외합니다. 환경 변수 안내가 필요하면 `.env.example`에 이름과 가짜 값만 기록하세요. `VITE_*` 값은 브라우저에 노출되므로 비밀 키를 넣으면 안 됩니다. 브라우저에 저장되는 퀴즈 기록과 감상 노트는 저장소에 포함되지 않습니다.

## PWA 설치와 오프라인

배포 주소를 휴대폰 Safari 또는 Chrome에서 열고 로그인한 뒤, 하단에서 **오프라인 준비 완료**를 확인하세요. iPhone은 공유 메뉴 → 홈 화면에 추가, Android Chrome은 메뉴 → 앱 설치/홈 화면에 추가로 설치합니다. 지원되는 브라우저에는 앱 내 설치 버튼도 표시됩니다.

- 서비스 워커는 배포 빌드에서만 등록됩니다. 로컬 검증: `npm run build` → `npm run preview`.
- 단어·문법·퀴즈 화면과 앱 아이콘을 기기에 저장합니다. 최초 방문과 로그인은 온라인 연결이 필요합니다. 외부 웹폰트와 일본어 음성의 오프라인 사용 여부는 기기 지원에 따라 달라집니다.
- 로그인 페이지, 인증 콜백, API 요청, 외부 리소스는 캐시하지 않습니다. 온라인 접근 거부/로그인은 캐시된 앱으로 대체하지 않습니다. 오프라인 저장을 마친 기기에서는 로그인 서버에 연결하지 않고 학습 화면을 열 수 있으므로 개인 기기에서 사용하세요.
- 새 버전은 사용자에게 업데이트를 안내한 뒤 활성화합니다. 앱 데이터는 브라우저에 저장되고 기기 간 동기화되지 않습니다. 브라우저의 사이트 데이터 삭제 시 학습 기록과 오프라인 파일도 사라질 수 있습니다.
- `node --test tests/pwa.test.mjs`는 빌드 후 실행하며 설치 자산, 오프라인 응답, 로그인 페이지 캐시 차단을 검사합니다.
- 아이콘 원본은 `scripts/generate-icons.py`로 재생성할 수 있습니다.
